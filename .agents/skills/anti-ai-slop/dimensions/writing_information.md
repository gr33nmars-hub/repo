# Dimension Review: Informational Writing

Use for summaries, explainers, manuals, internal notes, documentation, blog posts, FAQs, and general prose.

## Purpose

Informational writing should reduce the reader’s uncertainty or effort. It should not merely look organized.

## Common generic patterns

| Pattern | Visible sign | Risk |
|---|---|---|
| Broad opening | “In today’s world...,” “X is increasingly important...” | Delays the useful point |
| Obvious framing | Defines basic terms the audience already knows | Wastes attention |
| Excessive structure | Too many headings, bullets, tables, and “key takeaway” boxes | Looks clean but breaks flow |
| Generic helpfulness | “It is important,” “This can help,” “This is useful” | Does not say why or for whom |
| Equal weighting | Every item receives the same length and tone | Hides priority |
| Safe conclusion | “Ultimately, it depends...” | Leaves the reader without a decision |
| Prompt/template residue | “As an AI,” unfilled placeholders, leftover outline labels, unused checklist rows | Breaks trust and shows the output was not adapted |
| Support-tone loop | Repeated apology, “I understand your frustration,” policy restatement, no resolution path | Sounds helpful while avoiding the user’s actual problem |
| SEO filler | Keyword-stuffed headings, generic FAQ blocks, “ultimate guide” sections, duplicate-intent paragraphs | Optimizes for search-shaped content rather than reader progress |

## Review checklist

- Does the first paragraph answer the actual question?
- Is there a clear reader, scenario, or use case?
- Are obvious statements removed?
- Are examples concrete enough to verify understanding?
- Are lists used because comparison or scanning matters, not because the draft lacks flow?
- Does the conclusion add a decision, next step, or synthesis?
- Are placeholders, leaked instructions, or unused scaffold sections removed?
- For support or help content, is there a concrete resolution, escalation path, or limitation?
- For SEO content, does each section add unique reader value beyond the target keyword?

## Rewrite patterns

### Replace broad setup with context

```text
Weak: Effective communication is essential in today’s workplace.
Better: This memo is for managers who need to explain a delayed launch without creating panic or hiding responsibility.
```

### Replace empty importance with consequence

```text
Weak: Data quality is important for decision-making.
Better: If duplicate accounts remain in the CRM, the sales forecast will overstate pipeline by roughly one renewal cycle.
```

### Replace equal bullets with priority

```text
Weak:
- Cost
- Speed
- Quality

Better:
1. Quality is the gating factor because the output goes to customers.
2. Speed matters only after manual review drops below 30 minutes.
3. Cost is secondary until volume exceeds the current support budget.
```

## Acceptance criteria

- The reader can state the main point after the first section.
- The output includes at least one concrete context marker.
- Generic intensifiers are removed or replaced with mechanisms.
- Structure follows the task, not a default template.
- The ending tells the reader what to do, remember, or decide.
