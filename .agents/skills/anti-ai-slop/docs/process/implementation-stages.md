# Implementation Stages

1. Inventory existing code and docs.
2. Read constitution, glossary, architecture principles, and product principles.
3. Write or update `spec.md`.
4. Resolve clarification items.
5. Generate checklist, plan, and traceable tasks.
6. Implement one vertical slice.
7. Run validators and project tests.
8. Record evidence.
9. Review the PR for coherence and anti-slop risks.
