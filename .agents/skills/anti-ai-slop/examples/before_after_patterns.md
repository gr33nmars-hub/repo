# Before / After Pattern Examples

Use these examples as repair references. Do not copy them verbatim unless they match the task.

## Informational writing

```text
Before: Data-driven decision-making is important for modern organizations.
After: This review focuses on one decision: whether the sales team can trust the current pipeline number for next month’s hiring plan.
```

## Professional report

```text
Before: The results underscore the importance of a comprehensive approach.
After: The results change the priority order: fix intake quality first, then automate routing. Automation before intake cleanup will amplify the current error rate.
```

## Marketing copy

```text
Before: Unlock the power of AI for your team.
After: Upload a sales call and get a manager-ready coaching summary with objections, missed questions, and follow-up risks highlighted.
```

## Emotional/social writing

```text
Before: Failure is not the opposite of success. It is part of the journey.
After: The first version failed in a room of eight customers. Nobody complained about the algorithm. They complained that the export button was hidden.
```

## Web/UI design

```text
Before: A hero badge says “Live AI” with a blinking green dot, but no live process exists.
After: Remove the blinking dot, or connect it to a real “Processing transcript” state with a visible status label and reduced-motion fallback.
```

## Slide title

```text
Before: Market Trends
After: Compliance teams are buying automation, but trust in review accuracy remains the adoption blocker
```

## Code

```text
Before: A script logs all errors as “Something went wrong.”
After: Distinguish invalid input, missing configuration, upstream timeout, and unauthorized access. Add tests for each path.
```

## Generated visual

```text
Before: A glowing robot points at a floating dashboard with unreadable charts.
After: Show the actual review screen with realistic labels: flagged call, coaching note, reviewer decision, export state.
```
