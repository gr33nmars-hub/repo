## Первый проход (до упрощения игровых экранов)

После исправлений повторно проверены все пять вкладок, блокировка других игр активной рукой blackjack, денежные подписи и отключение полей ставки в заблокированном состоянии. Пустые состояния, первая загрузка и ошибка/повтор сверены по исходникам и доступным экранным состояниям. Правила выплат, игровые формулы, вероятности и серверный контракт не менялись. Не запускались новые раунды, чтобы не менять сохранённую активную руку; состояние ожидания и завершения раунда проверено по управляющим веткам исходников. Рабочий браузерный просмотр был примерно 1024×780; минимальный размер 920×640 отдельно не задавался доступным инструментом просмотра.

Проверка текущей версии: реальные компоненты просмотрены во временной изолированной странице при **920×640** и **1280×800**. Проверены ставка, активная рука, split, страховка, неверная сумма, ожидание, блокировка, пустой результат и завершённый раунд; дополнительно просмотрены лобби и пустая история. После корректировки компактности рулетки измерено переполнение X=0, Y=0 при 920×640 с результатом; число 17 и чёрный сектор совпали с остановкой шарика. Тестовые результаты не отправлялись в API, сохранённый профиль не изменялся. Временная страница проверки удалена.

Проверки: `npm run lint`, `npm run build`, `npm run test:unit` (15/15), механический detector (без замечаний), `git diff --check`. Правила, вероятности, коэффициенты, серверные контракты и реальные результаты сохранены.
