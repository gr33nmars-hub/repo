# План завершения рефакторинга NOIR Casino Club

## Цель

Завершить проверенный рефакторинг backend и подготовить NOIR Casino Club к открытой разработке на GitHub. Целевая оболочка — Tauri v2.

## План

- [x] **Blackjack и Shoe:** `act(action, balance)` — единый вход для действий; баланс и фаза проверяются до перехода, карты Shoe и состояние движка нельзя менять через выданные наружу ссылки. Проверка: тесты действий, инвариантов и восстановления сохранённого состояния.
- [x] **Слои домена и API:** правила и переходы отделены от DTO-проекций и persistence-кодеков; mutable proof/result данные копируются на границах. Проверка: доменные, API и regression-тесты на отсутствие утечек ссылок.
- [x] **SQLite и баланс:** списание защищено `BEGIN IMMEDIATE`; независимые ключи запросов не позволяют параллельно потратить один и тот же остаток. Проверка: конкурентный тест с балансом ровно на одну ставку.
- [x] **Атомарное обновление снимка сервиса:** при обновлении устаревшего состояния сначала читаются игрок, Blackjack и server seed; Blackjack откатывается к checkpoint, если проверка ledger не проходит; поля сервиса публикуются только после успешной загрузки и валидации. Regression-тест подтверждает, что некорректный seed не меняет in-memory состояние и revision.
- [x] **Правила и fairness:** общие seed/hash helpers вынесены в доменный модуль с совместимыми импортами; зафиксированы deterministic vectors, ставки и границы игр. Roulette отклоняет неверный тип выбора до розыгрыша, slots проверяют контейнер остановок до `len()`, `GameResult` проверяет тип fairness. Проверка: фиксированные векторы и тесты граничных входов.
- [x] **Стиль и документация:** стандартные типы Python, dataclasses и типизация; удалены неверные сведения о горячих клавишах и старой оболочке. Проверка: Ruff и mypy для Python 3.10 на Linux/Windows.
- [x] **Локальный backend gate:** текущий рабочий tree прошёл `pytest` (371 passed, один upstream warning), Ruff check/format и mypy для Python 3.10 на Linux/Windows.
- [x] **Clean-copy прогон после атомарного refresh:** свежая копия 161 исходного и документационного файла, без `.git`, `.venv`, кэшей, `node_modules` и собранных артефактов.
