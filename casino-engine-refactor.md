# Упростить игровые движки казино

## Цель
Сохранить правила и API игр, убрать лишние связи и дублирование состояния, восстановить корректную загрузку блэкджека.

## Задачи
- [x] Исправить учёт карт в `blackjack.py`: в сохранённом состоянии карты текущей раздачи и сброса должны быть непересекающимися. Проверка: сохранение и загрузка завершённого натурального блэкджека и нескольких последовательных раундов проходят без потери карт.
- [x] Вынести общий `GameRules` и источник случайности в небольшой независимый модуль; импортировать `Blackjack` напрямую из `blackjack.py`, убрать обратный импорт из `games.py`. Проверка: импорт модулей в любом порядке и текущие вызовы сессии работают.
- [x] Оставить единый путь для блэкджека через `start` и действия; убрать неиспользуемый автоматический `Blackjack.play()` и мёртвую модель `BlackjackHand` после проверки внешних импортов. Проверка: API и интерфейс используют только поддерживаемый путь.
- [x] Разделить `restore_state()` на разбор формата, миграцию старых версий и проверку инвариантов; сохранять проверку состава башмака, ставок, статусов и выплат. Проверка: версии 2/3/4 загружаются, поддельные состояния отклоняются.
- [x] Упростить типизацию реестра игр: быстрые игры хранить в типизированном реестре, блэкджек — отдельным полем с сохранённым публичным доступом. Проверка: не нужен `type: ignore`, метаданные и маршруты не меняются.
- [x] Проверить расчёт выплат слотов и рулетки на граничных исходах и запустить весь backend-набор: `uv run --directory backend python -m unittest discover -s tests -q`.

## Готово, когда
- [x] Все backend-тесты проходят, загрузка сохранённых раздач корректна, текущие ответы API и правила выплат сохранены.

## Примечание
В рабочем дереве уже есть изменения. Перед реализацией сверить актуальную версию файлов и сохранить существующие правки.
