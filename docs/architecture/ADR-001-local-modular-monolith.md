# ADR-001: Локальный модульный монолит

## Статус

Accepted

## Контекст

NOIR Casino Club — Windows desktop приложение для одного локального профиля и виртуальных фишек. Tauri WebView запускает локальный Python/FastAPI sidecar; состояние игры и ledger хранятся в SQLite. Синхронизация между устройствами, общий multiplayer-профиль и платежи не входят в текущий продуктовый контекст.

## Рассмотренные варианты

| Вариант | Выгода | Цена |
|---|---|---|
| Локальный модульный монолит | Одна транзакционная граница; простая установка и восстановление; слои можно отделять внутри процесса. | Sidecar и WebView нужно запускать и завершать согласованно. |
| Разделить backend на сервисы | Независимое масштабирование и развертывание частей. | Сеть, распределенные сбои и отсутствие атомарности не решают текущую задачу продукта. |

## Решение

Оставить один локальный FastAPI sidecar и один SQLite профиль. Организовать Python код по слоям domain, application, persistence и transport; держать React клиент и Tauri lifecycle в отдельных frontend границах.

## Последствия

- Команда, правила, профиль, ledger и idempotency response фиксируются одной SQLite транзакцией.
- Масштабирование через сервисы отложено до появления отдельного deployment или ownership требования.
- Desktop lifecycle, loopback адрес, token, nonce и CSP образуют один проверяемый контракт.

## Пересмотреть, если

Появится облачное сохранение, общий профиль, multiplayer или независимый жизненный цикл backend компонентов.
