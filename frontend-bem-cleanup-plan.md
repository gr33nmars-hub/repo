# BEM и глобальная чистка frontend

## Цель

Унифицировать DOM-классы и CSS по BEM, убрать подтверждённо мёртвые правила и исторические дубли, сохранив игровые состояния и поведение.

## План

- [x] Сверить все frontend CSS-файлы с TSX и динамическими состояниями; зафиксировать мёртвые правила и повторы.
- [x] Перевести классы оболочки и лобби на блоки `app-shell`, `sidebar`, `lobby-page`.
- [x] Перевести общие игровые контролы и экраны блэкджека, слотов, рулетки и истории на BEM.
- [x] Добавить базовые классы к модификаторам итога истории и слотов.
- [x] Удалить правила несуществующих sidebar guest, вторичного заголовка, shell footer и структурный дублирующий слой; слить повторяющиеся декларации оболочки и истории.
- [x] Проверить DOM/CSS аудитом, lint, unit, build, diff и просмотром всех пяти экранов.

CSS-аудит проверил 7 таблиц стилей: все найденные классы соответствуют форме блока/элемента/модификатора; дублей селекторов в одинаковом контексте и повторов деклараций нет. Буквальный поиск не находит некоторые модификаторы, потому что они собираются из значений действий, цветов и состояний; их места формирования сверены вручную. Других подтверждённых неиспользуемых классов не осталось.

Визуально просмотрены лобби, активная рука блэкджека, заблокированные слоты и рулетка, список истории в открытом браузере (ширина около 940 px). Изменить размер viewport доступным браузерным управлением нельзя, поэтому мобильный вариант проверен по responsive CSS, но отдельно визуально не подтверждён.

Проверки: `npm run lint` — успешно; `npm run test:unit` — 18/18; `npm run build` — успешно; `git diff --check` — успешно (остались только стандартные предупреждения Git о LF/CRLF в ранее изменённых файлах).
