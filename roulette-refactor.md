# Рефакторинг рулетки

## Цель
Сделать рулетку игровым столом с читаемыми ставками и колесом, которое останавливается на результате сервера.

## Задачи
- [x] Перерисовать колесо: 37 карманов в европейском порядке, цвета и шарик → визуально есть сектор для каждого числа.
- [x] Связать анимацию с API: ожидание ответа, замедление на выпавшем секторе, безопасное завершение при ошибке и уходе со страницы → повторная ставка не застревает.
- [x] Пересобрать панель ставок и результат в стиле игрового стола → выбор и выплата заметны с первого взгляда.
- [x] Проверить сборку и ручной сценарий ставки на обычной и узкой раскладке → число под указателем совпадает с ответом.

## Готово, когда
- [x] Ставка, колесо, баланс и результат проходят полный раунд без рассинхронизации.
