# Барабаны слотов

## Цель
Барабаны прокручивают фиксированные ленты и плавно останавливаются на выбранных сервером позициях без подмены символов после анимации.

## Задачи
- [x] Сервер выбирает независимую позицию на каждой ленте и возвращает позиции с лентами; выплата считается по центральной линии. Проверка: результат совпадает с тремя позициями, RTP остаётся 88,7%.
- [x] Интерфейс запускает непрерывное вращение сразу после ставки, затем доводит каждый барабан до серверной позиции слева направо. Проверка: видимые соседние символы сохраняют порядок ленты, последний кадр совпадает с результатом.
- [x] Сохранить остановившиеся барабаны и итог раунда в согласованном состоянии, поддержать снижение анимации и ошибки запроса. Проверка: повторная ставка и переход между комнатами не создают скачка или зависшего вращения.
- [x] Привязать каждую остановку к заранее опубликованному хешу seed; раскрыть seed после раунда и проверить результат в браузере.
- [x] Запустить backend-тесты и сборку frontend; проверить анимацию в браузере.

## Готово, когда
- [x] Три ленты крутятся непрерывно и постепенно тормозят, а выигрыш определяется видимой центральной линией.
