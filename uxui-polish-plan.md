# Шлифовка UX/UI NOIR Casino Club

## Цель

Уточнить подписи денежных итогов и поведение заблокированных ставок, убрав повторяющийся баланс без изменения правил игры или API.

## Задачи

- [x] Подписать чистый итог в последних раундах лобби и рулетки → Проверка: у `+N`/`−N` рядом видна подпись «Итог».
- [x] Удалить повторное отображение баланса из консоли слотов → Проверка: баланс остаётся в оболочке, доступная сумма видна у ставки.
- [x] Блокировать поле и кнопки изменения ставки в `BetControl` при занятости/недоступности игры → Проверка: при активном blackjack на слотах и рулетке нельзя менять ставку или отправить раунд.
- [x] Повторно пройти лобби, blackjack, слоты, рулетку и историю, включая пустые/ошибочные состояния по коду и доступные сценарии в UI → Проверка: названия сумм и состояния действий согласованы, изменённые игровые данные не затронуты.
- [x] Запустить frontend lint и build, затем сверить diff и статусы документов → Проверка: обе команды завершаются успешно; в плане и аудите нет открытых задач.

## Готово, когда

- [x] Все наблюдаемые денежные итоги имеют ясную подпись, блокированная ставка не редактируется, а дубли баланса слотов убраны.
- [x] Все пункты плана завершены и каждое замечание аудита исправлено либо обосновано.

## Ограничения

Только интерфейс. Не менять правила/вероятности/выплаты, серверные контракты, начальные данные и активную сохранённую руку. При последующей переработке игровые экраны проверены в viewport 920×640 и 1280×800 на изолированных UI-примерах: см. `game-ui-simplification-plan.md`. Сохранённые раунды не изменялись проверкой.
